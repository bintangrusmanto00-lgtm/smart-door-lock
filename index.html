Alur kerja perangkat Arduino Uno + FPM10A

Arduino menangani pendaftaran dua kali scan, pencocokan template, dan penghapusan ID. LED hijau + bunyi pendek menandakan berhasil; LED merah + bunyi panjang menandakan gagal.

Catatan: sebelum tombol Hubungkan Arduino ditekan, operasi di sini hanya simulasi UI. Setelah terhubung (Chrome/Edge), tombol Enrollment, Verification, dan Delete mengirim perintah ke sensor FPM10A lewat USB. Program perangkat keras: Sensor_Door_lock_lengkap_.ino.

Tentang Sistem

Sensor membaca sidik jari dan mengirim hasil ke Arduino lewat serial (UART). Arduino memutuskan akses, menyalakan LED, dan menggerakkan solenoid door lock melalui rangkaian driver. Modul DFPlayer Mini memutar pesan suara dari kartu SD: "Silakan masuk" saat akses diterima dan "Coba lagi" saat ditolak. LCD 16x2 menampilkan status singkat: siaga, memindai, akses diterima atau ditolak, serta hitung mundur penguncian pintu.

Mode simulasi dan mode perangkat keras. Tanpa koneksi, seluruh pemindaian dan status adalah simulasi di browser. Setelah Arduino dihubungkan, hasil pemindaian berasal dari sensor FPM10A; website hanya menerima ID dan hasil cocok/tidak cocok, bukan data biometrik.

Sistem Kunci Berbasis Arduino dan Sensor Sidik Jari FPM10A · Kelompok 3. Proyek UTS Praktikum Algoritma dan Bahasa Pemrograman Komputer, dikembangkan sebagai media demonstrasi autentikasi sidik jari.

Teknologi: HTML, CSS, JavaScript. Simulasi Arduino Uno, sensor fingerprint FPM10A, enrollment, verification, delete, solenoid door lock, modul suara DFPlayer Mini, dan LCD 16x2.
